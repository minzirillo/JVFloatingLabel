# Laboratoire 4D v17 / 4D v17 lab

**Français**

Ce dossier conserve le laboratoire binaire d’origine et le composant compilé pour **4D v17** (`JVFloatLabeledTextFieldv17 Lab.4dbase/`), ainsi que `BuildSettings/BuildApp.xml`.

Ce fichier XML est la configuration de génération v17. Il contient un chemin de licence local à une machine.

Le tout est gardé comme référence. Il n’est pas utilisable avec **4D 21 R4** : cette version ne charge pas ce composant compilé. Le projet à ouvrir est `Project/JVFloatLabeledTextField.4DProject`, à la racine du dépôt. Sa configuration de génération est `Settings/buildApp.4DSettings`.

**English**

This folder keeps the original binary lab and compiled component for **4D v17** (`JVFloatLabeledTextFieldv17 Lab.4dbase/`), plus `BuildSettings/BuildApp.xml`.

That XML file is the v17 build configuration. It contains a machine-local licence path.

Everything here is kept for reference. It cannot be used with **4D 21 R4**: that version does not load this compiled component. Open `Project/JVFloatLabeledTextField.4DProject` at the repository root. Its build configuration is `Settings/buildApp.4DSettings`.
